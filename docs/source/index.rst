CAHRA-Challenge Metrics Docs
============

This codebase provides a way to run metrics on entries to the 2025 CAHRA Challenge. Specifically, this code is for the conformational heterogeneity challenge dataset.

.. note::

   This project is under active development. Metrics (and implementation) are subject to change (if required). An explanation of these metrics is available on the `CAHRA challenge website`_.

   .. _CAHRA challenge website: https://heterogeneity.notion.site/conformational-heterogeneity-scoring-metrics
